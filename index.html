System requirements.

Mostly Code is designed to stay responsive on everyday Windows PCs. A faster CPU and SSD help when working with larger projects.

Minimum

Ready to code

  • Operating systemWindows 10 64-bit or Windows 11
  • Memory4 GB DDR4 RAM
  • ProcessorIntel Core i3-6100 or AMD Ryzen 3 1200 (or equivalent)
  • GraphicsIntegrated graphics with DirectX 11 support
  • Storage100 MB free space
  • Display1280 × 720
Recommended

Extra smooth workflow

  • Operating systemWindows 11 64-bit
  • Memory8 GB DDR4 RAM or more
  • ProcessorIntel Core i5-8400 or AMD Ryzen 5 2600 (or better)
  • GraphicsModern integrated graphics or dedicated GPU
  • StorageSSD with 250 MB free space
  • Display1920 × 1080

The editor can open and edit files without installing a compiler or interpreter. Running C/C++, Python, or JavaScript files requires the corresponding toolchain (such as GCC, Python, or Node.js) to be installed separately.
